# 公开源码边界

此仓库是当前源码的独立公开副本，使用新 Git 历史，不继承开发仓库的旧提交、作者邮箱、删除过的文件或运维资料。

本项目自有代码与随附文档采用 [MIT License](../LICENSE)。该许可不覆盖游戏资源或第三方软件，具体边界见[源码与许可说明](LICENSING.md)，依赖及字体来源见[第三方项目说明](../THIRD_PARTY_NOTICES.md)。

## 脱敏处理

- 仅选择源码、测试、示例配置和原创站点标识；排除所有运行输出、账号导出、数据库、原始包体、生成数据、游戏素材与第三方二进制运行库。
- 部署主机别名、镜像仓库、站点配置和本机路径改为示例值；运维记录、现场安装脚本、版本输入绑定不公开。
- Master 解密参数和 CRI 媒体密钥改为本地环境输入；SDK 示例不含应用密钥。
- 邮箱、QQ、站点及 GitHub 地址是维护者明确批准公开的信息。
- `.gitignore` 排除环境变量文件、凭据、证书、运行数据和游戏资源；它不替代每次提交前的扫描。

## 验证范围

公开前使用 Gitleaks 和已知私有参数/路径检查，并验证独立代码构建、代码发布包摘要、剧情选段与启动流程的单元测试。此检查不等同于已审计所有历史：历史没有导入。

运行完整站点需要另行配置游戏内容快照；游戏资源、Live2D Core 和生产环境不属于本仓库。不要把示例配置直接部署到生产服务器。

## 后续同步

不要将原开发仓库的 `.git`、整个工作区或旧分支直接推到此仓库。后续变更应在公开工作副本中提交；从开发工作区同步时仅选择必要源码，并重新审查密钥、本机路径、部署信息和生成内容。

公开副本不带私有计分核验报告，默认 evidence 明确为 unverified。正式计分规则由内容快照提供；研究证据需要由部署者另行核验后接入。
