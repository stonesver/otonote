# OtoNote 使用指南

OtoNote 是 BanG Dream! Our Notes 的非官方玩家资料站，提供角色与卡牌、音乐与谱面、剧情阅读和配队计算。本站与游戏官方无隶属关系，最新内容以游戏内公告为准。

- [打开网站](https://ournotes.stonebg.cn/)
- [关于本站](https://ournotes.stonebg.cn/global/zh-CN/about/)
- [源码与许可](LICENSING.md)

## 从哪里开始

下表链接进入国际服中文页面。使用前请通过站点的区服和语言选择器确认自己的游戏环境；日服与国际服的内容进度、名称及数值可能不同。

## 服装图鉴

从「角色·养成资料 → 服装图鉴」进入，或在角色页点击「服装」。点击乐队徽标、角色头像或输入名称筛选，再次点击已选图标可取消筛选，筛选链接可以分享。列表只加载预先生成的全身静态图片，不下载模型。同一套服装的多个模型合并收录，预览按钮打开 Live2D 工作台并选中对应模型，点击加载后开始预览。

服装卡展示初始获取或关联成员卡的获取条件；未知条件标为待确认。配置日期沿用区服时间约定（国际服 UTC+8、日服 UTC+9），到达日期不保证游戏内已经开放。列表仅包含游戏内可换装服装，剧情造型仍在 Live2D 工作台浏览。当前快照缺少服装资料或图片时会显示待补充。

## 怎样理解资料与计算结果

本站展示整理后的内容快照，并非游戏服务器的实时状态。资料更新可能滞后，尚未整理的条目也可能缺少图片、音频或关联信息。遇到不一致时，请先比较区服、游戏版本和站点资料版本。

计分和配队结果用于比较与规划，受卡片养成、技能、谱面、规则版本和输入参数影响。请阅读工具内的适用范围、参考估算或验证状态；不要将未验证结果视为已获得实机确认。规则不可用时，部分计算功能会暂不可用。

工具准备期间显示加载状态；工具页首次打开时，以条件栏和五组配对卡片骨架配合轻量音符、声波与扫光动效提示加载，遵循系统减少动态效果设置。准备完成后显示可操作内容，加载失败时可重新加载。卡组配队提供「自动配队」和「队伍比较」。歌曲计算的结果与演出设置位于输入区下方，可通过「查看计算结果」直接跳转。

本站的资源展示与分享功能不改变游戏内容的版权归属。下载、转载或再次分发素材时，应遵循对应权利方的要求，详见[许可说明](LICENSING.md)。

## 配队、发挥和培养计划

工具能力以当前页面及其资料版本为准；没有受支持资料时不会提供计算结果。

左侧条件面板可直接选择歌曲与难度、使用卡片、演出模式、发挥条件、优化目标和推荐方向，并调整卡片养成与账号加成，点击「推荐队伍」开始计算。「高级设置」中的编成限制和精细演出条件直接展开，无需再点击折叠箭头；激奏条件随演出模式显示。计算中显示当前阶段，可停止计算；完成后收起条件，点击「修改条件」可重新调整。

账号加成中的角色评级按每页 5 位编辑，可筛选当前队伍、全部角色或某个乐队，并按姓名搜索。筛选和翻页保留本次填写；「评级全满」仍作用于全部角色，应用前会检查各页输入，取消不会写入本次计算。

先选歌和难度，再选择卡片范围。没有导入卡库也能选「参考卡库」或「手选卡片」。参考队伍按卡片满养成比较，账号、乐器和 TGW 仍按页面设置；结果不代表这些卡已经拥有或练好。

卡片范围旁可分别多选「成员乐队」与「留影关联乐队」，默认不限。乐队以 Logo 按钮展示，悬停可查看名称；图片不可用时回退为文字。成员按所属乐队筛选；留影只要包含所选乐队任一登场角色即可入选，跨乐队留影也适用。同一筛选内多选表示任选其一，成员与留影的限制分别生效，并与卡片范围、属性等条件共同限制参与计算的候选。筛选后不足五位不同角色或五张留影时会提示调整；修改筛选需重新计算，不会修改实际卡库。

「培养后配队」可以从卡库或手选卡开始。默认保持突破、觉醒，只提升允许培养的卡；可指定技能等级、单卡目标和最多培养张数。结果列出需要提升的项目，并在实际记录齐全时分别比较当前养成方案、目标队伍现在的表现和培养后的表现。材料消耗尚未核算，应用或保存方案不会改写实际卡库。

参考发挥、练习中的发挥和理想发挥是公开的模拟条件，不是对玩家水平的判断。所有候选使用同一批原始时机和漏按样本，再分别计算技能带来的判定与连击变化。可在高级设置中调整整体偏差、难段，或输入逐音符记录。FC 不等于全 JUST；样本最高分和低分也不是理论极值或实战保底。

推荐最多展示三套有区别的搭配：平均分、较低分表现、激奏段落任务。若同一队适合几个方向，会合并显示。未填对手时，名次只是计算条件，任务计数优势不表示必拿第一。结果数量按实际搭配显示。手机端每行展示一组成员与留影，队长单独标记；手机端卡名收起，桌面端保留卡名；属性、乐队、稀有度、养成数值与技能标记均直接叠加在卡图上，未记录养成显示「—」。「编辑队伍」载入当前方案，「保存队伍」保存命名队伍。卡面可查看技能说明，「查看技能发动」在弹窗中展示回放，分数保留整数展示，精确值在「计算详情」中查看。

「配队推荐」「估分与选曲」「活动收益」共用顶栏导航、条件控件与卡面样式；切页时保留当前队伍、歌曲、难度和计算设置。桌面左侧修改条件，右侧查看结果与完整队伍；手机按需展开条件。相同养成来源在队伍旁统一标注，混合来源保留未记录等提示。活动收益的刷取阶段、已有挑战 pt、账号加成、奖励卡与选曲筛选可在主区域直接调整；已有完整队伍时可从卡库范围切换为当前队伍。搜索范围（快速推荐 / 完整比较）、节能计算与计算按钮在桌面和手机底部常驻，节能计算默认关闭，可手动开启以降低持续计算负载，开始计算后条件收起，进度和完成、停止、错误状态显示在底部操作栏：状态图标、当前阶段计数与耗时持续可见，完成时短暂强调并保留简短状态；浮条不提供详情入口，范围与精度说明保留在结果区；结果保持原位置，不自动跳转或增加查看结果按钮，停止与续算沿用当前任务。计算中隐藏重复的计算详情，失败原因在底部完整显示；配队推荐开始计算时同样自动收起条件，顶部可通过「修改条件」重新展开，完成后保持结果全宽；进度、停止和重新推荐集中在底部浮窗。配队推荐、收益配队和活动曲冲榜在首个队伍出现前共用音符、声波与卡片扫光动效，出现首个结果或停止计算后撤下，并尊重减少动态效果设置；使用说明保留在刷取计划下方。活动页标签依次为收益配队、活动曲冲榜、加成速算。冲榜歌曲展示本期活动属性与难度色；开始计算后收成所选歌曲的封面、属性与难度摘要，完成或停止后仍保留，可通过「更换歌曲 / 难度」展开全部活动曲。更换谱面会结束旧计算并清除旧结果，奖励卡和账号加成直接在左侧计算条件中调整。估分页可切换「单曲估分」和「队伍选曲」：单曲随条件变化自动估分，选曲手动启动；两种模式计算时均自动收起左侧条件，顶部可重新展开，完成后保持全宽结果。进度、停止、重新计算与高级设置统一放在底部浮窗；高级设置仍保留逐音符判定、激奏情景与账号加成。左侧导航将配队推荐、估分与选曲、活动收益和卡库与队伍集中在「我的工具」；「浏览」下的活动信息、资料浏览和更多工具按需展开，进入资料详情时自动展开所属分组。卡库与队伍在所有页面共用同一浮窗。导航切页后会保持目录位置，并显示当前选中项。

各工具通过「卡库与队伍」浮窗共用卡库和命名队伍。点击结果的保存队伍按钮，填写名字后保存；到另一个工具选择「用于当前工具」，歌曲与活动条件仍使用该页设置。在「队伍比较」可换歌比较，也可选择最多 12 首歌及保留的预设数量。各队使用统一发挥和名次条件；曲池默认等权，不代表抽歌概率。重新导入养成后会重新核对未完成目标；旧预设缺失养成时会标成参考队伍。

计算可以停止，已完成的方案会保留。培养组合较多时只比较设定数量，页面会标出未完成范围；缩小允许培养的卡片或提高上限后可重新计算。实用推荐不穷举所有队伍，不保证全卡库最优。

## 活动收益

「收益配队」支持我的卡库、全卡库参考或当前队伍；全卡库参考按卡片满养成比较，账号加成仍使用页面设置。成员乐队与留影关联乐队可分别多选，与歌曲的演奏乐队筛选独立；普通阶段遵守所选卡片乐队限制，临时纳入的奖励卡也受限制。后续挑战默认不限乐队，卡库来源仍由「挑战卡片范围」独立选择；需要相同限制时，可打开「挑战卡片范围」中的「沿用乐队筛选」开关。条件区和结果均说明后续挑战的乐队限制，修改后需要重新计算。活动曲冲榜提供独立的成员／留影乐队筛选。

「收益配队」默认展示活动、卡片范围、收益目标、耗火预算和可打难度；刷取阶段、已有挑战 pt、账号加成和谱面筛选可直接调整；后续挑战的范围、档位与难度在刷取计划下方直接调整，搜索范围和节能计算位于底部操作栏，无需高级设置。可切换自动选曲或指定谱面。开始计算时桌面和手机均收起条件，结果占满主区域；首个队伍生成前显示音符与卡片扫光占位动画，出现首个方案即撤下，实际进度仍保留在底部；顶部保留条件摘要与「修改条件」，可随时展开后再次收起；停止后保留已得到的方案，重新完整比较仍从头搜索并复用可用估分缓存。

推荐将道具与活动 pt 总收益、耗火和场次放在同一摘要中，收益明细位于队伍之前，按阶段列出次数与收益；歌曲显示封面和难度色标。普通演出与后续挑战通过标签切换，共用总收益摘要，每次只展示所选阶段的完整配对；卡面保留属性、养成与技能标记，乐队标识位于右下方。桌面和手机均点击「回放」在弹窗查看技能记录。两阶段可以使用不同队伍。「比较方案」位于结果顶部，多套候选默认展开。道具 / pt 优先目标与收益 / 时长排序合并在比较区内，候选紧凑展示；比较列表显示本页范围与总数，每页最多八套。参考养成、未证明最优和计算不完整会保留标记。

「加成速算」填写游戏中的两项加成与稳定评分，收益即时更新；「活动曲冲榜」独立选择活动歌曲、卡片范围和出分目标，支持暂停后继续搜索。临时纳入奖励卡后，无论是否已持有，都按所选奖励卡养成参与本次计算；调整临时养成及保存队伍不会修改实际卡库。

## 歌曲排行榜

榜单默认逐难度比较，每次显示 50 张谱面，向下滚动接近列表底部时继续追加；也可点击「加载更多」。横向滚动查看其余指标，已展开的明细在追加时保持原位，修改筛选或排序后从首批重新展示。

选择「达档综合力」并设置目标档位，可按各歌曲、各难度达到该档位所需的参考综合力由低到高比较；「每首歌仅显示一张」会保留当前排序最靠前的难度。目标分数线采用所选版本的数据，综合力按当前 AP 与技能条件的基准线性估算，向上取整到千位。该门槛用于选曲参考，不代表实际队伍必达，也不等于谱面操作难度；未经核验或缺少数据的谱面不参与综合力排名。

## 查看技能发动

歌曲计算、配队推荐、队伍比较、AP 估分、活动选歌与收益方案都提供技能发动记录；配队推荐直接提供「查看技能发动」入口。活动推荐只在点击「回放」后加载弹窗内容，正文保留发动顺序摘要。排行榜在歌曲明细中提供同样的入口。其他批量结果只在展开时生成记录，收起即可停止尚未完成的计算。

彩色时间条对应五次成员技能发动，背景显示音符密度。点击时间条可查看卡牌与留影效果、发动和结束时间、延长时长，以及窗口内音符的实际回放倍率和得分。最高／最低顺序可以切换；平均分来自多种顺序，没有唯一的发动过程。重叠窗口的音符分数包含全部效果，不能作为可相加的单卡贡献。

激奏另有技能发动、结束及效果变化记录；随机情景注明样本种子。挑战回放保留活动加成，导入判定时仅展示指定回放。只比较综合力而未进行歌曲计分时展示配对条件；手填评分或纯奖励换算不生成技能时间轴。

## 导入自己的养成

所有工具页都有「卡库与队伍 → 卡库 → 导入备份」入口；独立「我的养成」页也使用同一份实际记录。选择兼容的 JSON 后，先核对卡片及养成信息，再应用到自己的卡库；未知或缺失字段不应当作已经读取的实际状态。

也可在卡库中选择「从游戏截图导入」。截图只在当前浏览器处理：自动定位不同列数的角色卡或留影列表，再识别卡面和可见养成。请使用未裁切的横屏截图，保留至少两列完整卡牌；底部半张卡会跳过。等级页与特训页可以一起导入，截图类型判断不确定时手动选择。模糊、缩放过小或无法可靠对齐的数值会留空，请对照裁片补齐、处理冲突后再保存；不要把空白当作零级。不同机型仍建议先用少量截图核对。

本地养成导出工具的支持范围、配置要求和操作步骤见[工具说明](../packaging/growth-tool/README.md)。该工具在自己的电脑运行并连接官方服务，与网站上的登录入口是不同运行方式；不要把本地工具的凭据处理说明套用于所有在线功能。登录可能影响已有游戏会话，运行前请阅读工具说明。

导出的 JSON 由自己保管。反馈问题时只提供复现所需的最小样例，并先移除账号信息；不要公开密码、登录令牌、设备信息或有效 SDK 配置。

## 跨工具使用卡库与队伍

「卡库与队伍」居中打开，手机上接近全屏。我的队伍中可新建、命名、复制、重命名和删除队伍，删除后可撤销。队长是中间位置，可在编辑中交换；一组成员和留影一起移动。重名不会覆盖已有队伍，只有「更新这套队伍」会改动原记录。

在卡库选择「批量录入」，点击卡面或勾选框连续选择；翻页、切换筛选或成员卡／留影时保留勾选，也可选择本页或只看已选。点击「设置养成」，按实际情况选择初始养成、当前阶数满级、满养成或自定义数值，再一次保存。默认保留已记录卡片的养成，只有勾选「同时更新已记录卡片」才会修改；整批操作可一次撤销，保存后仍留在卡库。自定义空白字段保留原值，新卡从 1 开始；整批校验通过才写入。若卡库在其他页面发生变化，会保留输入并要求重新核对。

多选时，卡面和底部勾选区都只切换选中状态。各卡养成不同时，先「结束多选」，再逐卡调整；原勾选保留，重新进入多选后可继续。打开逐卡编辑会滚动到表单，可使用「保存并录入下一张」：保存当前卡后，按当前筛选顺序打开下一张，自动跨页；在「未记录」范围中，已保存的卡会从列表移出。录入结果仍存于当前浏览器的对应区服，可通过卡库备份导出。

实际养成放在卡库，培养目标和参考假设放在队伍里。编辑培养计划不会修改真实持有记录。导入个人养成备份前会显示区服、卡片数量和增减，确认后替换实际记录，命名队伍保留。导入队伍备份则追加新队伍；旧版预设可以选择来源带入，原记录保留。

活动限制由对应工具提供。不能使用的卡片说明原因，活动加成不等于禁用；含冲突卡牌的队伍仍可保存，并可复制调整。个人队伍不改变歌曲排行榜的固定比较基准。

资料只在同一浏览器、同一网站来源和同一区服内共用。更换设备、浏览器或从本地预览转到线上前，请分别导出卡库养成与队伍备份。


## 歌单与计算范围

页面常驻的「我的歌单」与「卡库与队伍」共用入口区域，在普通音乐页面也能管理歌单。
浮窗分为「我的歌单」与「站点推荐」，列表提供封面拼图、歌曲名预览和数量；点击卡片进入详情。
新建或保存修改后留在详情，可继续编辑或返回列表，不会自动应用到计算器。
在工具里点击「用于当前计算」才切换范围；普通页面点击「选择计算工具」，再选择配队、队伍选曲
或活动收益，带入歌单但不自动计算。计算条件中的「管理歌单」也可打开同一管理界面。
更多菜单支持重命名、复制、单份导出和删除；删除后可撤销。每首歌可保存指定
难度，或选择「全部难度」以包含当前及以后新增的难度。空歌单可以保存，但不能计算。

歌单保存在当前设备、当前浏览器的 localStorage，按网站来源与区服隔离，不自动同步到
其他设备。管理面板可导出全部歌单，导入先预览区服、数量与不可用条目，确认后追加为
新歌单。歌单备份与卡库养成、队伍备份分别导出；导入其中一类不会覆盖另外两类。
浏览器清理网站数据会删除歌单，存储失败时页面明确提示未保存。

同一歌单在不同工具中可能有不同的有效数量：它仍须满足当前活动、模式、难度、等级、
乐队与属性限制。不能使用或缺资料的条目显示原因，并保留在歌单中。范围为空时必须
调整条件，不会自动切换全曲。各工具记住上次范围；配队和活动按模式分别记忆。
页内工具切换可携带本次范围，携带数据只存在当前浏览器会话中，不是公开分享链接。

「调整本次范围」默认只展示已选歌曲，点击「只看已选」可切回全部歌曲继续添加；以「应用本次调整」更新当前会话草稿。需要长期保存时，展开「将调整保存为歌单」，另存新歌单或显式更新原歌单。也可在范围卡片恢复原范围。
临时修改刷新后仍保留，关闭标签页后不保证恢复。队伍选曲可勾选谱面保存、加入已有
歌单，也可保存全部搜索结果，跨页勾选仍保留；保存面板展示歌曲与谱面数量。

配队的「歌单逐曲推荐」为每张谱面分别推荐队伍，可能使用不同编成；停止后保留已完成
谱面的结果。它不寻找一支覆盖多曲的共同最优队伍。队伍选曲则固定一支队伍，以现有
AP、满生命条件比较各曲；单曲估分只使用当前歌曲、谱面与发挥设置，不展示歌单范围，
也不受已保存歌单或空范围限制。歌单范围仅在「队伍选曲」中生效。

工具已限定曲目时不显示歌单范围：当前谱面配队、单曲估分、活动指定谱面、本期活动曲
和后续挑战曲池均不受已保存歌单限制；切回自由选曲时恢复原歌单选择。
后续挑战按本期官方曲池与难度条件计算；为空时调整难度或关闭后续挑战，不能扩大到非活动曲。活动快速比较
还会从有效范围中选择最多六张主阶段候选，页面区分有效范围、本轮计划与实际覆盖。
「完整比较」仍限定在当前范围；「扩大到全部可用谱面」解除歌单限制，但保留活动等条件。

站点推荐目前提供「短时长候选」与「低等级练习候选」，按当前目录摘要生成，显示筛选依据，
不会先执行全曲配队搜索。可通过调整范围保存为自己的歌单。短歌不等于活动效率最优，
低等级不保证个人稳定发挥；推荐也不宣称任何歌曲对所有队伍都是高分最优。

歌单管理支持按名称与备注搜索，详情区分已保存数量与当前工具下的可用歌曲／谱面数。
备份入口收在「备份与保存位置」中。编辑器每页最多展示 30 首歌曲，显示封面、属性、乐队
和带等级的难度按钮；搜索支持歌名、乐队或 ID，筛选支持属性、乐队、难度、等级和激奏段落。
筛选只改变浏览结果，不会删除已选谱面；可切到只看已选或重置筛选。每个难度可以独立选中，
选中状态同时有勾号与边框。切换难度后保留键盘焦点，未保存的修改关闭前可选择继续编辑或放弃。
移动端编辑器底部保留数量摘要和保存／应用按钮，收起工具条件后仍可查看当前范围。
