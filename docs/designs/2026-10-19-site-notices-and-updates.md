# 公告与页面更新提示

用户已确认先实现公告和更新提示，反馈渠道暂缓。

## 公告

沿用私有 ON 控制台、BFF 和资源节点之间的权限边界。控制台增加公告管理，通过现有受认证节点传输读写；节点单独保存草稿和公开公告文件，不依赖游戏资源生产、R2 或预渲染成功。公开网站仅能读取单独导出的 JSON，不能访问草稿、管理身份或写接口。

支持普通提示、维护、故障，按全部区服或 Global/JP、多个逻辑页面路径前缀投放。范围最多 32 个，匹配任意一项即展示一次；全站与具体页面互斥。新记录使用 paths 数组，保留旧单值 path 的读取和发布兼容。标题、正文为纯文本，可附站内详情链接，支持英文内容与中文回退。可预览、保存草稿、发布、撤回，设置生效和结束时间。草稿修改不会直接改变已发布版本，更新与撤回检查修订号，避免覆盖他人修改。公开文件原子替换，草稿和公开版本各自持久化；发布成功以公开文件写入为准，不需要两个存储的跨事务提交。

普通提示可关闭，本地按公告 ID 与修订号记忆；维护、故障保持可见。客户端自动过滤过期公告，网络错误不阻塞页面，已有公告仍按本地时钟过期。第一版由管理员发布，自动健康检查接入留待后续。

## 更新提示

全局页面挂载轻量通知组件，同时覆盖冷启动与预渲染路径。每三分钟检查一次公告和当前区服的已交付页面状态，标签页返回前台时检查，后台暂停检查。失败静默重试，避免重叠请求和快速切回造成密集请求。

版本状态复用已对外服务的预渲染 current/complete.json，经独立的只读 URL 暴露；不直接观察远端资料指针，避免新资料已发布但本机 HTML 尚未完成时误报。校验 codeId、内容指针与组合身份后，与当前文档固定的代码和内容身份比较。分别显示网站功能更新、资料更新或两者都有，用户可刷新或稍后；同一目标版本选择稍后后不重复提醒。

不自动刷新、不替换当前资料快照、不打断计算和编辑。用户主动刷新走正常页面加载与已有未保存检查。

## 交付与验证

增加节点公告存储与 API、BFF、管理页面、公共组件、Nginx 只读路由和本地预览支持。配置默认关闭，新部署按文档显式配置目录、站点、发布人员和公开文件路径。独立的版本状态路由读取现有交付完成回执，无需更改发布顺序。

验证公告权限、参数、修订冲突、草稿隔离、发布撤回、持久化、定时和范围、关闭记忆、版本比较、请求失败及客户端生命周期，并运行现有管理及启动回归、独立代码构建。线上配置切换与真实发布后验证单独记录，不能以本地测试代替。

## 视觉完善（用户后续确认）

沿用站点现有纸色 `--paper-light`、墨色 `--ink`、莓红 `--lacquer` 和 `--font-body`。根据用户最新要求，将公告与更新拆开：公告位于顶部导航下方，更新提示位于底部，均相对正文区域居中。圆角 20–24px，轻阴影，不再采用窗口内嵌卡片。圆角状态标签区分普通提示、维护、故障，正文保持墨色阅读层级。普通公告的关闭按钮保留完整可访问名称，视觉为 ×，点击区域 44px。

更新提醒使用轻量更新图标、短标签和紧凑操作区；刷新为莓红圆形图标按钮，稍后为关闭图标按钮，操作语义不变。桌面和手机均默认单行，状态标识在左、标题和正文在中、操作在右。中间文字超宽才往返滚动，悬停或聚焦暂停，减少动态效果时静止；原生 dialog 支持由按钮打开独立详情面板，桌面居中、手机底部展示，内部包含标题、正文与详情链接；打开时隐藏滚动提示条，避免重复显示。Escape 或关闭按钮关闭面板并由浏览器恢复焦点。尺寸变化由 ResizeObserver 重新测量，普通轮询不重建未改变的文字轨道，避免重复从头滚动。公告默认高度 54px，更新提示默认高度 44px，操作固定在右侧。公告按钮为 44px，更新按钮按用户要求缩为 32px、圆形底色 28px，四周留有间距，并提供 title 与 aria-label。横幅宽度最多 560px，手机两侧留 16px。顶部公告最高 32dvh，长内容内部滚动；收起后保留状态与数量，按每条公告修订在当前标签页记忆，新修订到达时展开。折叠公告保留独立的关闭普通公告按钮，点击后仅记忆当前普通公告修订，不清除维护和故障；底部更新独立显示，不受公告收起影响，稍后仍按更新目标记忆。手机有配队工作台入口时底部提示上移；dialog 或手机导航打开时隐藏。挂载在 main 之外，避免正文过渡的 transform 改变 fixed 定位，不占用正文布局。

管理控制台的公告预览同步使用纸色卡片和相同状态标签。维护标签文字适当压暗，在其浅色背景上的计算对比度约 5.13:1。保留键盘焦点与减少动态效果设置，不增加装饰性动画。
