# 三服独立认证读取

按用户确认的范围推进：暂不开发 App，不引入短期会话。每次养成/抽卡请求携带明确区服，独立完成公共发现、SDK 认证、已有角色检查及功能读取；玩家凭据仅在本请求中使用。

## 边界与数据流

- 港澳台、EN、韩服使用网站既有 serverId。SDK 应用/渠道配置与游戏区服分别建模；目标主机必须同时匹配所选区服和固定白名单。不通过语言猜服，无角色时在 PlayerPreLogin 停止，不创建角色。
- 公共服务器发现和所选区服的公开 Version 分别接收官方最低版本提示，验证版本格式后各最多重试一次。将发现得到的版本冻结为本请求版本，用于 SDK app_ver、RPC 头、PlayerLogin protobuf 和导出来源；认证后要求更新则停止，绝不重放密码登录。不执行远程代码，不把请求头兼容冒充协议已验收。
- 网关保留同源、nonce、no-store、并发及限流。支持显式 serverId；历史客户端省略时保留港澳台默认。capabilities 按区服响应，维护检查选择相同区服。每次请求新建游戏/SDK 客户端，不跨用户缓存认证。
- 导出养成与抽卡携带真实 serverId 和本次 clientVersion；前端导入、保存、查询验证必须与当前区服一致。旧港澳台文件保留兼容，冲突来源拒绝。未知资料不猜卡、不补成满级。
- 抽卡时间按明确展示规则处理：港澳台 UTC+8、韩服 UTC+9、EN 显式 UTC；日期过滤、记录与分享采用同一规则。EN UTC 为网站显示约定，不声称是官方日界线。
- Google 独立调查游戏 SDK 的 sns.login 与 Google server auth code。普通网站 Google 身份不能直接当成游戏身份；授权回调与凭据归属未验证前不开放可点击的伪登录入口。

## 验证

使用三服合成服务响应覆盖正确主机与已有角色、跨服拒绝、空角色停止、独立认证、官方升级协商与版本一致、认证阶段不重试、维护区服、前端存储隔离与时间边界。只读实测公共服务器发现及版本；维护期间不进行玩家认证。真实账号与游戏内数据对账、生产部署另行验收。

将通过验证的成果合并到 codex/release-2026-10-18，保留其他任务成果，不直接合入 main，不自动推送部署。


## 实服验证发现

用户授权使用现有榜单探测账号。服务器只读挂载既有凭据，独立认证读取三服养成和抽卡成功。额外使用服务器匿名管道与内存中的真实前端转换器校验 EN/韩服，不将真实玩家快照落盘或传回本地；Docker 日志关闭，只回传检查结果与数量。

EN 养成按网站当前规则转换并在内存中保存成功。韩服养成包含当前网站内容库尚未收录的卡牌，因此完整导入被拒绝；不能静默丢弃这些卡牌后替换原卡库。发布验收需要更新公开内容库后再次核对。两服抽卡解析成功，旧内容映射下分别有 3/4 条未知奖品，保持未知。

真实账号读取成功不等于游戏客户端 UI 已对账；发布边界详见三服读取交付文档。
