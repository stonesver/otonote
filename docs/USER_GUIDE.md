# OtoNote 使用指南

OtoNote 是 BanG Dream! Our Notes 的非官方玩家资料站，提供角色与卡牌、音乐与谱面、剧情阅读和配队计算。本站与游戏官方无隶属关系，最新内容以游戏内公告为准。

- [打开网站](https://ournotes.stonebg.cn/)
- [关于本站](https://ournotes.stonebg.cn/global/zh-CN/about/)
- [源码与许可](LICENSING.md)

## 从哪里开始

下表链接进入国际服中文页面。使用前请通过站点的区服和语言选择器确认自己的游戏环境；日服与国际服的内容进度、名称及数值可能不同。

| 想做的事 | 入口 | 使用方式 |
| --- | --- | --- |
| 找角色和卡牌 | [角色档案](https://ournotes.stonebg.cn/global/zh-CN/characters/) | 从角色进入相关资料，查看成员卡、留影和技能信息；也可使用站内搜索。 |
| 找歌曲和谱面 | [音乐](https://ournotes.stonebg.cn/global/zh-CN/music/) | 查看曲目与难度，使用页面提供的音频或谱面预览；未提供的媒体不代表游戏中不存在。 |
| 阅读剧情 | [剧情](https://ournotes.stonebg.cn/global/zh-CN/stories/) | 选择故事和章节；支持的章节可选取台词生成分享长图。 |
| 比较配队 | [卡组配队](https://ournotes.stonebg.cn/global/zh-CN/tools/deck-builder/) | 选择成员卡、留影和养成参数，再比较不同编成。 |

| 核对资料版本 | [更新记录](https://ournotes.stonebg.cn/global/zh-CN/updates/) | 查看当前资料的游戏版本、生成时间与整理状态。 |

## 服装图鉴

从「角色·养成资料 → 服装图鉴」进入，或在角色页点击「服装」。点击乐队徽标、角色头像或输入名称筛选，再次点击已选图标可取消筛选，筛选链接可以分享。列表只加载预先生成的全身静态图片，不下载模型。同一套服装的多个模型合并收录，预览按钮打开 Live2D 工作台并选中对应模型，点击加载后开始预览。

服装卡展示初始获取或关联成员卡的获取条件；未知条件标为待确认。配置日期沿用区服时间约定（国际服 UTC+8、日服 UTC+9），到达日期不保证游戏内已经开放。列表仅包含游戏内可换装服装，剧情造型仍在 Live2D 工作台浏览。当前快照缺少服装资料或图片时会显示待补充。

## 怎样理解资料与计算结果

本站展示整理后的内容快照，并非游戏服务器的实时状态。资料更新可能滞后，尚未整理的条目也可能缺少图片、音频或关联信息。遇到不一致时，请先比较区服、游戏版本和站点资料版本。

计分和配队结果用于比较与规划，受卡片养成、技能、谱面、规则版本和输入参数影响。请阅读工具内的适用范围、参考估算或验证状态；不要将未验证结果视为已获得实机确认。规则不可用时，部分计算功能会暂不可用。

工具准备期间只显示加载状态，完成后再显示可操作内容；加载失败时可重新加载。卡组配队统一使用「帮我配一队」和「比较队伍 / 换卡」，已移除旧版高级面板、步骤向导和重复摘要。歌曲计算的结果与演出设置位于输入区下方，可通过「查看计算结果」直接跳转。

本站的资源展示与分享功能不改变游戏内容的版权归属。下载、转载或再次分发素材时，应遵循对应权利方的要求，详见[许可说明](LICENSING.md)。

## 查看技能发动

歌曲计算、配队推荐、队伍比较、AP 估分、活动选歌与收益方案都提供「查看技能发动」。排行榜在歌曲明细中提供同样的入口。批量结果只在展开时生成记录，收起即可停止尚未完成的计算。

彩色时间条对应五次成员技能发动，背景显示音符密度。点击时间条可查看卡牌与留影效果、发动和结束时间、延长时长，以及窗口内音符的实际回放倍率和得分。最高／最低顺序可以切换；平均分来自多种顺序，没有唯一的发动过程。重叠窗口的音符分数包含全部效果，不能作为可相加的单卡贡献。

激奏另有技能发动、结束及效果变化记录；随机情景注明样本种子。挑战回放保留活动加成，导入判定时仅展示指定回放。只比较综合力而未进行歌曲计分时展示配对条件；手填评分或纯奖励换算不生成技能时间轴。

## 导入自己的养成

配卡工具提供「选卡库 → 我的卡库 → 从游戏导入我的养成」入口。选择兼容的 JSON 后，先核对卡片及养成信息，再应用到自己的卡库；未知或缺失字段不应当作已经读取的实际状态。

本地养成导出工具的支持范围、配置要求和操作步骤见[工具说明](../packaging/growth-tool/README.md)。该工具在自己的电脑运行并连接官方服务，与网站上的登录入口是不同运行方式；不要把本地工具的凭据处理说明套用于所有在线功能。登录可能影响已有游戏会话，运行前请阅读工具说明。

导出的 JSON 由自己保管。反馈问题时只提供复现所需的最小样例，并先移除账号信息；不要公开密码、登录令牌、设备信息或有效 SDK 配置。
