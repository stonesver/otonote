# 工具加载与计算进度

## 范围

已确认的工具工作台界面先提交为 `79f8929`。本轮独立优化配队、估分、活动收益页面，以及共享「卡库与队伍」弹窗。数据、账号养成和计算规则沿用网站内容版本；没有发布线上或修改玩家卡库。

## 加载诊断与修改

`inventory-catalog` 经由 `game-database` 导入完整游戏资料库，导致计算工具同时请求道具、成长档案、条件、目标、摘要与技能索引等无关内容。拆出 `game-card-data`，只读取成员、留影与技能三个集合。完整资料页继续通过 `game-database` 获得原有接口和校验。

原共享弹窗在判断能否复用工具数据之前，就导入了完整 `shared-team-data`。现在先判断上下文：计算工具只补充轻量展示映射；其他页面同时启动必需内容的读取和模块加载，复用 runtime 内容快照的请求缓存。按钮悬停或获得焦点时只预热代码，不读取账号、不开启弹窗实例。弹窗立即展示加载骨架，等待期间可关闭；加载失败可重试。

## 进度反馈

计算区域新增紧凑进度条：标题、当前阶段的完成 / 总量、正在处理的对象或说明。未知总量采用不定进度；阶段进度不是总耗时估计，搜索分支变化时不伪造百分比。停止、失败和完成有独立状态；修改条件隐藏旧进度，已结束 worker 的迟到消息不能恢复它。

- 配队：谱面准备、养成范围、卡片配对、候选筛选、精算等现有 worker 阶段。
- 活动收益：当前批次的谱面比较数量、歌曲、收益目标，单曲内部编成阶段。内部通知按阶段切换或约 120 ms 节流，忽略没有阶段的候选结果事件。
- 活动曲冲榜：准备卡片、筛选与完整复算的真实阶段计数。
- 快速推荐完成明确标注可继续完整比较；不将完成当前批次解释为全卡库最优。
- 原有停止与错误处理保留，动效尊重减少动态效果设置。
