# 港澳台账号响应的滚动发布兼容

## 线上复现

2026-10-18 发布自动版本协商网关后，旧页面仍在预渲染和用户已打开的标签页中运行。网关成功读取养成并返回 HTTP 200，但旧 `convertGrowthSnapshot` 要求 `source.region === 'TW/HK/MO'`，新响应将其统一为 `global`，导致合法港澳台账号被提示“当前只支持台港澳服养成”。账号认证已完成，因此游戏会话可能被挤下线。

## 修复与验收

保留港澳台历史 `region: TW/HK/MO`，同时提供明确的 `edition: global` 和 `serverId: global-hmt`；EN/韩服继续用 region global 及各自 serverId。新网页已支持上述港澳台格式，区服隔离规则不变。兼容性不能只依赖用户刷新或前后端同时切换。

在真实网关调用路径的合成 RPC 集成测试中先验证港澳台旧标记及其他两服标记，复现失败再修复。部署新不可变网关后检查模块摘要、三服协商及来源身份；用旧版前端真实转换器验证合成港澳台响应仍可转换。不得为验证而反复使用用户账号登录。
