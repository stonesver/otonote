# 技能发动展示

已确认目标：让各工具的分数与技能发动过程可读、可比较，保持原有计分行为。

## 接入范围

- 歌曲计算：普通、激奏、指定判定回放；结果下展示五技能时间轴。
- 配队与队伍比较：每个具体队伍提供按需展开入口；纯综合力只展示技能条件。
- AP 判档：普通与挑战逐行展开，保留挑战活动上下文。
- 活动收益：选歌、收益配队、挑战出分和后续挑战各自使用其队伍及歌曲。
- 歌曲排行：对所选基准或自定义五技能按需精算；明确其综合力和精算结果，不冒充快速参考值。
- 手填评分、预算、纯奖励换算没有技能顺序，不生成虚构时间轴。

## 展示与数据

沿用站点字体、圆角和淡色底；五个槽位分别采用蓝、青、紫、橙、粉作为身份色。主视觉为带卡牌头像的五行时间谱，曲线密度放在同一刻度中；选中发动后展开时间、倍率、留影延长、条件状态及覆盖音符。键盘与窄屏同样可用。

最高和最低顺序分别回放；平均分不绑定唯一顺序。随机激奏展示样本种子及状态变化；不将样本极值称为理论极值。指定判定只显示该次回放。按现有计分时间戳计算覆盖，不另写近似计分公式；重叠窗口不作可加和的单卡贡献声明。

批量筛选不生成详细记录。统一可折叠组件在展开时启动 Worker，关闭或移除时取消工作；输入改变时旧视图销毁。主歌曲页复用已计算记录。错误可重试，不污染分数。

## 实施与验证

1. 扩展可选 trace 的最高/最低记录，不更改默认评分输出。
2. 实现共用时间轴数据、交互组件和按需 Worker；接入上述入口。
3. 校验最高/最低轨迹得分、技能边界、零增益/未生效、随机种子复现、挑战上下文、取消及窄屏。
4. 构建独立网页预览，检查真实内容页面；提交后构建正式候选，固定验证回执，检查旧版本再发布，保留回滚并验证线上页面。

## 视觉迭代：演出时间谱

按用户要求进一步优化共用组件。考虑了纯浅色精修、全深色面板、浅色详情搭配深蓝音轨三种方案，采用第三种：深色集中在时间谱，分数、配对和条件继续保持明亮易读。

- 色彩：时间谱底色 #202e45，正文 #263449，辅助文字 #657187；五条音轨保留蓝、青、紫、橙、粉的身份映射，深底上提高亮度。
- 字体：沿用站点正文字体，时间和分数使用站点等宽字体；编号只表示真实发动次序。
- 标志性元素：五轨发动谱、同刻度音符密度和带圆点的发动标记；补充图例。
- 详情：成员与留影双卡面、明确的槽位和发动序号、四项数据读数、生效状态标签。
- 窄屏：按组件实际宽度切换，成员名称与时间保留在上行，时间轨独占下行；最窄 320px 无横向溢出。
- 交互：方向键、Home/End 切换音轨；切换回放顺序保留所选成员；动效遵守减少动态效果设置。

改动限于共享 UI 和样式。计分、窗口模型和 Worker 数据不变。已检查桌面、390px 和 320px 页面、顺序切换与所选成员保持；既有六项技能回放测试通过。正式发布仍使用固定候选校验及两服预渲染验收。
