# 收益加成约束下的记分上界证明

对应 `bonus-constrained-score-bound.mjs`、`ordinary-score-bound.mjs` 的 `withMinimumBonus` 接口；搜索如何逐档排除、更改成员／留影集合与固定十卡后的配对划分，见[计算搜索说明](../reference/calculation-search.md)。

## 固定同一队伍的综合力、技能和加成

沿用已经审计的 `powerLinearUpperBound`、技能起止帧与包络的原生回滚误差 E。对于同一合法队伍：

`score <= P * H`, `P = sum(p(e))`, `H <= B*(1+E) + sum(g(e))`。

p(e) 是实际整数配对综合力，g(e) 是这个配对自己提供的技能增量。平均分用五位置增量的均值（每张卡在120个顺序中各位置出现24次），最低分也不高于该均值；最高分用该配对五位置的最大增量，放宽了位置唯一性但不会排除真实队伍。卡片的能力、技能、收益加成始终保留在同一条边上。

令目标加成和为 A，考察必要条件 `A >= T`。任意正 lambda 和非负 mu 都满足：

`lambda*P + H <= base + max_legal_matching sum(lambda*p(e)+g(e)+mu*a(e)) - mu*T = Z`。

右边的最大匹配保留五个配对、成员角色互斥、留影唯一、必选配对、必选成员／留影和队长。它没有把高分取自一个队伍、高加成取自另一个队伍后误当成可达结果。由平方非负：

`score <= P*H <= (lambda*P+H)^2/(4*lambda) <= Z^2/(4*lambda)`。

每一次 lambda/mu 探测都独立有效。倍增、二分及有限轮参数更新只决定界有多紧，不要求对偶收敛，也不将匹配目标当作原生分数。加成最大匹配已严格低于 T 时，该子域为空，可返回0；资料／量级不支持时返回 Infinity，交给原搜索处理。

## 整数代理和浮点方向

匹配器只接受安全整数。每次按最大绝对操作数缩放，将代理边权限制在约 `2^30`，然后对每条边向上取整；匹配器的强制顶点奖励与五轮增广均保持安全整数。每条边先加入绝对误差余量，抵消除法、缩放及连乘可能产生的向下舍入。

`mu*T` 的相减可能发生消减，因此最终余量依赖 `base + 5*最大操作数 + mu*T` 的绝对量级，不能仅对小残差乘一个相对系数。最后向上平方取整并保留独立余量。原生 float32 综合力、音符记分和状态机误差仍由原有系数及 E 负责，这里没有修改它们。

## 组合约束与原奖励函数

若胜者必须同时有 `primaryBP>=T1`、`secondaryBP>=T2`，任何非负整数 a、b 都给出必要条件 `a*primaryBP+b*secondaryBP>=a*T1+b*T2`。用多个方向只收紧上界，不缩小真实搜索。超过安全整数范围的方向必须放弃。

T1/T2 必须从原奖励函数的整数取整结果求逆，不能直接拿最大加成作阈值。奖励存在平台时，稍低加成也可能给出相同主收益。每个可达档位独立处理，不能假设奖励或 CP 随档位单调。只有全部可能严格改进完整目标元组的子域均被排除，才能证明第一名；期望分精修另有目标，不应用仅收益元组的终止条件。

`bonusConstraintWitnesses` 只提供合法匹配建议，可能尚未达到该加成阈值，必须完整120顺序评分并按原收益转换后才能更新最佳队伍。它们不构成证明本身。缓存按固定歌曲、账号、规则、技能配置与目标创建；规则对象在任务中不可变，修正规则应创建新对象。

## 独立验证

- 纯数学测试独立枚举2160支合法队伍及每队120个技能位置顺序，覆盖同角色成员变体、留影选择／配对、队长、必选／禁用分区、最高／平均／最低界、可达与不可达加成阈值；所有界均不低于相应穷举最优。
- 另一个冲突样例中，高能力队无法提供高加成，高加成队无法达到高档位；上界严格低于档位门槛，但没有从真实卡库删除该卡。
- 已有原生评分小卡库独立穷举（两种配置共4800队，每队完整120顺序）增加条件加成上界校验，覆盖根和必选／禁用分区，确认新界不低于条件子域内的原生最优。
- 纯界测试与原生交叉核对分别验证。活动收益另有独立目标、续打整数消费和组合条件的枚举回归。性能数字只取不中断的正式数据运行，不使用跨主机挂起的测试墙钟。

## 跨谱面的归一化包络

普通演出的实际配对能力只读取歌曲 `_musicType` 和 `_bestMusicTagIDs`。按这两项和同一账号／卡库／养成／目标配置分组；难度、音符时间线和档位门槛仍为每张谱面独立建立。当前分组入口禁用活动 power 适配（普通模式），不适用于挑战或非 AP 情景。

对于谱面 c 的档位门槛 Qc>0，原上界提供 `score_c/Qc <= P * (base_c/Qc + sum(g_c(e)/Qc))`。每个分组取这些 base 的最大值，并对同一配对 e 的 gain 分别取跨谱面最大值，得到覆盖组内每张谱面的共同归一化包络。实际队伍不能同时拥有来自不同谱面的技能增量，但这个放宽方向只会增大上界。浮点误差先用全池五卡的绝对技能幅度覆盖，再归一化并向上留量。Q 缺失或非正时该包络不参与剪枝。

加成条件下的联合界使用 `integerScore=false`，保留小数；只有归一化上界严格小于1时才证明相应组中没有任何谱面能到达该档位。不能把这个无单位比值先向上取整再作阈值比较。纯数学双谱面反例及原生小卡库验证同时覆盖此接口。

跨谱面的获胜域比单曲多一个维度：主收益严格提高；主收益不降且次收益严格提高；两种收益均不降且谱面时长严格更短。grade 目标先覆盖所有更高档位。对每个档位，这些域全部排除后才可排除节点。先对卡片集合 include/exclude，再对谱面集合二分，最后对固定谱面的完整配对作 Lawler 分区。每个合法候选都留在某个未处理域中，直到有安全界或真实评分将其排除。

初始化提供的结果仅用于选择合法队伍。本模块重建本次养成下的队伍、校验原始分数缓存上下文并重新套用本次 basis、预算和续打转换；旧收益总数不作为 incumbent。配对模型在本次分组内重建，不信任外部旧模型。全部剪枝节点也报告进度并 cooperative yield，避免只有实际展开节点才检查取消／时间预算。

双谱面 native oracle 共7,200支合法配对，分别独立评分、计算非单调档位奖励并比较道具、pt及grade的完整收益／时长目标。三个搜索目标均与穷举一致；故意篡高种子收益仍需重算后得到正确答案。全局证书仅证明所选域第一名，备选、未逐曲求出的配队及默认关闭的期望分 tie 不包含在证书中。

计算器缓存属于执行状态：迁移候选逐谱面完成后释放重放计算器；证明阶段仅按当前分组建立评分器和上界，组内全部分区耗尽后再释放。归一化包络在仍有未处理域时保持有效，释放不会把未处理域视作已证明。评分器源码、结果字段、缓存命中与未命中的数值路径保持一致。
