# 两服目录身份与版本差异

目录合并区分“同一个实体”和“同一份资源版本”。不得用本地化标题、导出文件哈希、文件大小、发布根目录或资源是否已下载，单独决定实体身份；也不得只凭相同数字 ID 合并。

| 目录 | 稳定身份依据 | 单独保留的版本差异 |
| --- | --- | --- |
| 角色 | Master 角色与头像原始资源路径、乐队、生日 | 头像、颜色、角色定位 |
| 乐队 | Master 乐队与标识原始资源路径、成员集合 | 标识、颜色 |
| 成员卡、留影 | 已验证的 Master 与原始资源绑定、角色、稀有度和属性 | 卡牌数值、技能 |
| 沉浸式场景 | 场景编号、乐队、原始背景地址 | 导出清单、时长、可播放状态 |
| Live2D | 原始模型地址、角色、用途与模型变体 | Bundle 版本、动作、表情、物理参数 |
| BGM | 命名音频 cue 与 cue 序号 | 音频导出和可用状态 |
| 乐队道具 | Master 与原始资源路径、乐队、资源组 | 等级与效果数值 |
| 技能 | Master 技能域与编号、效果种类、目标 | 等级与技能数值 |
| 漫画、表情、贴纸、背景 | 资源类型、经验证的原始资源地址、角色与乐队 | 图片版本、可用状态 |
| 道具 | 已有 Master 类型与图标资源绑定证据 | 数值和持有上限 |
| 歌曲、剧情 | 已有音频/谱面资源绑定、剧情场景与章节角色证据 | 谱面与剧情版本 |
| 歌曲榜 | 同谱面和实际参与计算的规则 | 两服分数线分别保留；规则或谱面真正不同不合并结果 |

`entity-identity.mjs` 集中管理实体规则与版本比较。目录入口调用真实规则，`mergeEditionRows` 只接受两边唯一的匹配；证据不足和一对多歧义保留记录。同编号但不能验证为同实体的记录标记为未知，不显示“某服独有”。优先展示当前服资源；当前服缺失而另一服可用时保留可用代表和真实来源。不得把两服数值混成一条计算输入。

旧画廊快照没有 `sourceResource` 时，仅从同一固定快照的 `public/gallery/manifest.json` 恢复绑定，并验证类型、编号、图片文件和 SHA-256 对应关系。缺少清单时使用保守的旧证据，不猜测资源地址。新的内容投影直接保留经过 Master/资源清单验证的原始地址。

CI 覆盖两个主服方向、翻译、图片重编码、资源重打包、导出路径变化、同资源的不同发现方式、缺图回退，以及冲突与歧义。集成测试编译真实目录入口，避免只测辅助函数而遗漏调用链。发布验收须回放实际固定的两服快照，检查所有共享目录，并检查目录项详情、模型、音频仍指向真实来源。
