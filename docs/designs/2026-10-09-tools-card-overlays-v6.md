# 工具原型 V6：紧凑条件控件与卡图养成叠层

延续 D 版工作台，落实用户对 V5 的四处修改。歌曲排行榜继续独立，不增加新的任务模块。仅修改独立原型；未接真实账号、持久化或计算接口，未部署。

## 1. 条件面板

- 选项改为独立的紧凑按钮，选中时显示浅底与边框；高度约 29–30px。
- 数字控件高度 32px，保留增减和常用值；活动的两项加成并排。
- 下拉框高度约 29–30px，菜单行 30px，减小圆角、阴影和内边距。
- 压缩分组与说明的间距，不限制桌面左侧条件区域高度。

## 2. 条件说明

标签改为非按钮元素。仅鼠标悬浮显示说明，移开或滚动后关闭；删除点击固定与焦点固定行为。触摸操作不模拟悬浮。

## 3. 配对卡图

- 稀有度、属性位于卡图左上，特训简写 `训2`，右上显示。
- 等级叠在左下；觉醒进度使用四个星形标记，已完成点亮，未完成灰显。
- 演出等级简写 `演2`；激奏同时显示类型与等级，如 `JUST 1`、`COMBO 3`、`LUCK 4`。
- 留影的稀有度、属性叠在自身缩略图左上，等级与特训仍叠在图上，与角色卡保持一致。
- 编辑面板右侧预览采用相同卡图叠层。

### 资源核对与边界

放大资源后确认，原 `Icon_Awakened` (`asset-6a40457373`) 是“覚醒済”文字贴图，不适合表示分级进度；`awakening_base` (`asset-0005154212`) 是粉色菱形底板，亦不是独立花瓣。

V6 复用游戏 `SpecialTraining` (`asset-02261a47eb`) 四角星素材来**示意觉醒级数**。这是原型的视觉表达，不代表已确认游戏中专用觉醒花瓣或每一阶段的素材映射。专用素材仍需后续资源补齐。数字继续是示例进度，并非用户实际卡库。

## 4. 卡片筛选

默认吸顶工具栏：

1. 搜索 + 成员卡/留影切换。
2. 颜色 + 乐队。
3. 稀有度 + 清除。
4. 可展开的技能筛选；演出/支援技能和激奏类型均保留。

技能筛选收起后仍生效，摘要显示已选条件。手机颜色以游戏属性图标展示，保留无障碍名称和提示。桌面卡片改为三列，手机为两列。

## 浏览器验证

- 桌面 1280×720：默认筛选区 148px，浏览区域 527px，余下约 379px 可展示卡片。
- 手机 390×844：默认筛选区 146px，浏览区域 553px，余下约 407px 展示卡片；页面宽度 390px，无横向溢出。
- 山吹 + LIFE 加成 + SSR 交集返回 2 张卡，技能筛选展开状态在更新后保留。收起后摘要继续显示 LIFE 加成并保持筛选。
- 键盘 PageDown 后列表发生滚动，吸顶区域顶部保持约 188.8px。
- 点击条件标签后移开鼠标：说明从显示变为隐藏，无固定状态。
- 活动加成增减与常用值：100 → 110，另一项设为 200；两列数字控件均为 32px 高。
- 配对预览包含不同示例觉醒进度（1、2、3）及 JUST / COMBO / LUCK；主展示和预览使用同一叠层函数。
- Node 语法检查、git diff 空白检查通过；浏览器无捕获的 error 日志。
