# 工具原型 V7：筛选边界与配对信息

按用户的三点反馈继续调整 D 版原型，保留独立歌曲排行榜。未接真实账号或计算接口，未部署。

## 筛选区视觉修正

截图中列表选中边框会露出到筛选栏侧边空隙。V7 将两者拆为独立区域：筛选栏固定在浏览区域上部，只有下方 `.card-grid-holder` 滚动；两者左右边界一致，列表溢出与选中轮廓被限制在列表区域内。

默认筛选高度约 146–149px，技能筛选仍可展开。编辑、切换和筛选后保留的是列表区域的滚动位置。

## 配对展示

- 留影使用完整宽度的卡图，不再使用 61–65px 的小缩略图加空白文字区。手机实测首张留影约 161×105px。
- 去掉额外的“留影”分类文字，标题放在图下。
- 成员卡与留影都在图上叠加稀有度、属性、乐队徽标、等级与特训。
- 成员保留演出、激奏技能等级；留影补齐激奏类型。留影类型来自公开目录，不额外编造激奏等级。
- 顶部只显示位置、匹配标识、队长；角色名放在成员卡名后面。
- 卡片目录与右侧预览亦使用同一圆形乐队徽标。

## 乐队与匹配

乐队徽标使用现有游戏乐队字标放入 22–23px 的圆形底座，底色按乐队颜色区分。悬浮说明与无障碍名称包含完整乐队名。这里未声称是游戏内已提取的独立圆形 sprite。

匹配由当前配对数据实时计算：

- 成员和留影属性相同 → `同属性`，悬浮说明对应属性。
- 乐队相同 → `同乐队`，悬浮说明对应乐队。
- 两项均相同 → 两个标识同时展示。
- 不匹配则不显示相应标识。这里只说明一致性，不宣称已经结算任何游戏加成。
