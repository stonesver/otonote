# 卡库与队伍浮窗优化报告

开发分支：`codex/shared-team-polish`。本轮优化对应[设计说明](2026-10-05-shared-team-polish-design.md)，在此前已发布的共用队伍功能上继续开发。已按用户后续授权推送并上线；发布记录见文末。

## 本轮改动

- 区服和“我的队伍／卡库”标签固定在顶部。新建、保存和应用有明确主次；备份及复制、重命名、删除收进次要菜单。保存按钮区固定在编辑器底部。
- 队伍、编辑器、选卡器及卡库统一卡牌信息：成员等级、突破、觉醒、两种技能等级、属性、乐队；留影等级、突破、属性。属性、乐队、稀有度和等级复用游戏素材，突破与觉醒用明确文字。缺图自动回退，未记录的数值显示横线。
- 区分当前养成、培养目标、参考养成和手选养成。培养计划只显示实际选中的培养卡；手改当前养成会切换为本队手选设置，保留卡库原值。
- 补充属性、乐队、角色、稀有度、持有范围、排序与清空筛选。连续选卡保留筛选和位置，不可选卡仍显示原因。
- 保存后在固定区域显示具体队名，区分新存与更新；编辑器标示未保存／已保存，未变更时禁用更新按钮。失败保留输入并说明原因。
- 卡库养成在卡片下方编辑。筛选或翻页后仍保留正在输入的内容，并说明该卡暂时不在本页。两个标签各自记住滚动位置。
- 点击浮窗外侧、Esc 或关闭按钮可以收起。再次打开保留草稿；选卡器打开时只关闭上层，避免拖动越界误关。首次打开立即显示加载状态，失败提供重试。

- 全量 Node 测试：发布前最终 999 项通过。新增卡片渲染、养成来源、筛选交集、连续选卡及浮窗关闭测试；相关用例加入固定候选门禁。
- 类型检查：680 个文件，0 错误、0 警告；25 项提示。

- 390×844 手机、1440×900 桌面、1800×1000 宽屏检查通过；手机浮窗内容没有横向溢出，五组配对支持横向浏览。桌面遮罩与宽屏侧栏均验证了外侧关闭，关闭后未保存名称仍在；嵌套选卡器关闭后父窗仍打开。

## 选卡规则补充与发布准备

用户确认本轮推送上线。选卡按目标槽位判断：同一位置可替换同角色其他卡，其他位置已使用的角色才禁用，提示写明占用位置。留影只限制同一张卡重复使用，不因同角色限制。实际活动禁用仍保留。

补充回归时发现，展示数据缺少单值 `characterId` 时，旧比较会把两个未定义值当成同角色。现改用正式卡表的角色身份，明确跳过被替换位置；回归覆盖五个槽位、同卡原位、同角色异卡、其他角色、留影及活动限制。
