# Our Notes 本地养成导出工具

支持港澳台、EN、韩服的 BHK 邮箱密码账号。电脑直接连接官方服务，不需要 ADB；读取角色卡、留影、乐器、角色评级和 TGW，导出 JSON 后可导入 Our Notes 配卡工具。Google 游戏授权尚未接通。区服与认证边界见[三服邮箱认证与账号读取](https://github.com/stonesver/otonote/blob/main/docs/reference/account-reads.md)。

`v0.2.0-alpha.2` 起的发行包内置 SDK 应用配置，解压启动后即可选择区服并登录，无需另行获取配置。使用包含区服选择的新版本；`v0.1.0-alpha.3` 及更早的下载包仅支持港澳台。网站语言与游戏区服分别选择，英文界面不代表已切换到 EN 区服。

## Windows 便携版

1. 完整解压 ZIP，不要在压缩包中直接运行。
2. 双击 `Start.cmd`，浏览器会打开本机页面。无需额外安装 Python，也无需管理员权限。
3. 在本机页面选择账号所属区服（港澳台、EN 或韩服），输入邮箱和密码，读取后点击「下载养成 JSON」。该区服须已有角色，工具不会创建角色。
4. 在网站选择同一区服，再到配卡工具的「选卡库 → 我的卡库 → 从游戏导入我的养成」选择 JSON，核对后应用。

关闭终端或按 Ctrl+C 退出。默认不自动写文件，结果仅在进程内存保留到退出；下载后的 JSON 由你自行保管。每次读取会清除上一次内存结果；需要保留时先下载备份。登录可能使官方游戏中的会话失效，验证码等额外验证不支持、不自动重试。

目标系统为 Windows 10/11 x64。便携包的 Windows 实机启动尚待验收，不能把文件组装成功当作实机测试通过。它不是手机应用，也不是浏览器直接运行的程序。

## Mac 便携版（Apple Silicon）

完整解压后双击 `Start.command`。工具自带运行环境，无需安装 Python，会打开终端和本机浏览器页面；后续登录和 JSON 导入流程与 Windows 相同。关闭终端或按 Ctrl+C 退出。

当前包仅适用于 Apple Silicon（M 系列芯片），不适用于 Intel Mac。当前为开发验证候选，未完成 Apple Developer ID 签名和公证；本机运行通过不代表从互联网下载后的 Gatekeeper 验收通过。不要通过关闭系统安全保护来运行。正式发布前还需完成平台分发验收。

上述三服能力描述当前源码。旧便携包可能仅支持港澳台；若界面没有区服选择，请核对安装包版本，不要使用港澳台入口读取 EN 或韩服账号。更新源码说明不会自动更新已下载的便携包。

若网站提示「网站资料中没有成员卡／留影，请更新资料后导入」，说明网站当前卡表无法覆盖读取结果，需要维护者检查内容生产与发布状态。切换电脑或重复登录不能补齐网站卡表；不要删除导出文件中的未知卡片来绕过校验，以免覆盖原有卡库。

## 从源码运行（Windows / macOS / Linux）

Python 3.9 或更新版本：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python launcher.py
```

Windows 将 `.venv/bin/python` 换成 `.venv\Scripts\python.exe`。

`python launcher.py --self-test` 检查依赖、RSA 运算和本机 HTTP 服务，不连接官方服务器，不使用真实账号。

## SDK 配置

发行 ZIP 内置 `sdk.bhk.xml`，启动时自动载入。配置标识游戏与渠道，与玩家账号无关；普通用户无需获取或填写配置。请完整解压并保留该文件。

需要覆盖配置时，可在浏览器选择不超过 6 KB 的最小 XML（仅保留示例中的七项），只在本次运行中生效；也可把有效配置保存成工具根目录的 `sdk.xml`，启动时自动载入。`sdk.example.xml` 是无应用密钥的模板，不是可用配置。

Git 源码仓库不保存有效 SDK 配置；下载的源码 ZIP 与便携 ZIP 均附带发行用配置。发行包不包含个人快照、邮箱、密码或登录令牌。源码许可只覆盖本工具代码，官方 SDK、游戏资源和第三方依赖保留各自权利及许可。

`v0.2.0-alpha.1` 未内置有效配置，建议直接更新到新版并完整解压。内置配置不改变本工具的非官方性质。

维护者打包时，通过 `python3 -m tools.build_growth_distribution --output NEW_OUTPUT --sdk-config APPROVED_SDK_XML` 显式提供发行配置；Windows 另传 `--downloads VERIFIED_DOWNLOADS`，Mac 使用 `tools.build_growth_macos` 的同名参数。构建器只接受受支持渠道的七项最小应用配置，不接受玩家凭据。未传该参数的源码构建仍只包含模板；不得把真实配置提交到 Git。

## 可审查边界

- 仅监听 `127.0.0.1` 的随机端口，校验 Host、Origin 和本次启动 nonce。
- 官方服务器与读取方法在源码中固定，不允许配置任意目标地址。
- 密码输入在提交后清空；不写凭据日志、状态文件或导出文件。
- 默认仅内存保存最近一次养成结果。显式传入 `--output 新文件.json` 才自动保存，且不会覆盖旧文件。
- 不保存设备绑定或账号会话；退出后再次读取需要重新输入。
- JSON 只导出支持的养成字段。未知字段不补全；网站按当前资料重新换算等级，回忆加成等未读取项目保持原设置。

网页不能直接执行本工具。完全免安装请使用网站的网页登录；本地工具的目的在于让登录请求从自己的电脑发送。
