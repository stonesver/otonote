对应[已确认设计](2026-10-05-shared-team-workspace-design.md)。开发分支为 `codex/shared-team-workspace`，按功能拆分提交；并行开发使用独立 worktree，审查后集成。已按用户后续指示推送并发布；发布验收记录见文末。

## 已完成的使用流程

所有工具页提供“卡库与队伍”入口。宽屏为侧边面板，手机为全屏面板。卡库记录实际持有和养成，队伍保存五组配对、队长与培养场景，工具页保留歌曲、活动和计算条件。

| 玩家操作 | 实现结果 |
| --- | --- |
| 查看或维护卡库 | 成员／留影、筛选搜索、逐卡实际养成、账号养成、备份导入预览与导出；导入覆盖可撤销 |
| 管理多套配对 | 自定义名称、新建、复制、重命名、更新、删除撤销、名称搜索；队伍按稳定 ID 保存，重名不会自动覆盖 |
| 在不同工具继续使用 | 应用已存队伍或恢复最近使用的队伍；保留当前页歌曲、难度和活动，取消旧计算；明确分享链接中的编成优先 |
| 保存计算结果 | 配队、挑战推荐及收益方案统一通过“存为队伍”进入命名；保存不会修改实际卡库 |
| 比较未养成的卡 | 当前养成、培养后使用、满养成参考、保留手选养成、试用未持有卡；培养目标与真实记录分开 |
| 进入受限制的活动 | 按工具声明检查卡、角色、乐队、属性、歌曲与难度；显示不可用原因，保留原队伍并允许复制调整；额外加成不当作禁用 |
| 使用非编队工具 | 仍可管理队伍和卡库，但不出现无效的“用于当前工具”按钮；固定基准排行榜不受个人编成影响 |

已保存队伍与卡库按账号区服隔离；兼容旧预设的显式导入，原记录保留。队伍备份默认合并。切区服或覆盖工作副本前处理未保存修改，跨窗口冲突保留输入，并提供另存副本。网页存储不可用、备份无效或版本不兼容时显示错误，不静默清空记录。

## 审阅顺序

1. 打开配队页的“卡库与队伍”，核对实际卡库与养成记录。
2. 在“日常稳分队”和培养计划间切换，确认实际值与计划值的区分是否直观。
3. 打开歌曲计算、AP 或活动工具，检查不用重选十张卡的连续操作体验。
4. 将工具推荐结果命名保存，再次应用，核对配对、队长和培养范围。
5. 用手机宽度检查浮窗、选卡和保存操作。
