# 工具原型 V14：快捷加成与技能发动模拟

## 本次六项修改

1. 账号加成增加一键满级；乐器和角色评级也有分组满级。使用设置草稿，应用才生效，取消仍舍弃。
2. TGW 将相同能力加成的等级合并，直接选择 Lv.1 / 2 / 3 / 4 / 5 / 6–10 / 11–15 / 16–20 / 21，对应 0 / 1 / 2 / 3 / 4 / 5 / 10 / 15 / 20%。区间取自现有 global-systems.json 快照的类型 7（所有能力值提升）；百分比单位按既有 scoring-rules/tgw-card.mjs 的 bp 换算。来源版本和文件 SHA 记录在 fixture-tgw.mjs。
3. 歌曲选择维持宽屏三列，谱面难度按钮从 V13 的 31px 缩到 24px；颜色、乐队、等级、难度组合筛选保持。
4. 配队结果与单曲估分增加技能发动模拟。提供播放/暂停、1/2/4 倍、进度拖动、下一次发动、重置。五个位置展示等待、发动、结束和剩余时间；紫色演出效果、金色留影延长。桌面并排展示时间线与当前效果，窄屏上下排列。
5. 推荐原因关闭按钮单独通过捕获阶段处理，先关闭原生 dialog 再清理辅助浮层、通知和计时器。保留顶部、底部、外围点击与 Escape。
6. 本次谱面成为条件面板外的独立模块，显示封面、歌名、乐队、难度和等级。条件面板只保留模式与发挥入口。

## 技能交互范围

技能效果按当前配对的真实目录技能与养成等级读取。演出示例包括 LIFE 门槛切换、留影 LIFE 回复、乐队对应的延长秒数，以及 PERFECT 判定门槛。激奏使用歌曲目录三段任务类型，区分成员与留影匹配，并演示 COMBO 门槛。

发动时间按歌曲时长等距分配；激奏阶段起止时间亦为示意。COMBO、LIFE 与判定是用户可调的假设，不是逐 note 回放。判定转换次数上限、LUCK 随机过程、实际名次及其余条件技能完整规则尚未接入。此面板不产出真实分数。

## 浏览器验证

独立临时标签页，1280×720，实际点击、键盘、选择与输入操作。

- 一键满级后五个乐器值均为 30，五个评级均为 50；取消后摘要恢复原有 0 队、1/1/1/1/1、TGW 1。选择 Lv.11–15 并应用后摘要显示 TGW 11（+10%）。
- 独立选曲后选择迷星叫 EXPERT，生成五组推荐；入口与条件面板分开。歌曲按钮实测布局截图为三列。
- 初始 LIFE 10 时，高松灯首次发动显示 +120%、LIFE 10 < 700；下一位置发动后，留影按 MyGO 分支回复 700，当前 LIFE 710。
- 要乐奈显示基础 5s 加留影延长 3s，发动时剩余 7.9s；PERFECT 显示 +150%，改 GREAT 后显示当前判定无加分。
- 播放时钟从 00:54 推进到 01:15；暂停与切换激奏后停播并重新定位。
- 迷星叫第一段 COMBO 显示成员/留影分别匹配；COMBO 从 30 改 0 后，要乐奈由发动中变条件未满足，匹配留影仍按示意生效。
- 推荐原因顶部关闭、底部关闭、Escape、外围点击均确认 dialog.open=false 且无 :modal 残留。V13 在新标签页未复现原用户无法关闭的状态，本次强化关闭路径后完成上述四项回归，不宣称已定位原根因。
- node --check 通过，临时验证页未捕获 console error。窄屏分支未重新浏览器验收。
