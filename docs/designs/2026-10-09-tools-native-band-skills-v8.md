# V8 原生乐队图标与技能悬浮说明

## 范围

沿用 V7 的工作台与卡片布局；本轮只修改独立原型。没有发布、提交或接入真实账号。

## 原生图标

五个乐队使用游戏 `Assets/AddressableResources/Band/{id}/band_small_Icon.png`，直接复制已有提取素材，不裁剪文字 logo。图标保持 22–23px，浮在角色卡和留影右上；选择列表右下显示，避免盖住选中标记。

素材来自本地公开资源目录 `resources/site-public/images/filter-bands`，SHA256 与该目录 provenance 校验一致；副本及来源记录在原型 `assets/bands`。

## 技能浮层

- 配队页面、队伍选择、卡片列表、编辑预览中的卡图都作为悬浮目标。
- 角色卡：队长技能、演出技能、激奏技能，包含技能名称、等级及完整效果条件。
- 留影：支援技能和激奏支援，包含具体效果与乐队限制。
- 角色演出和激奏按当前原型养成等级选择文案；队长、留影和目录列表使用最高级参考并明确标注，不推算留影技能等级。
- 技能文案从与卡片目录一致的公开快照 `card-detail-projections.json` 与 `game-database.json` 导出。129 张卡片都有技能记录，所有文案已解析，无插值占位符。
- 浮层放入当前弹窗或页面的 top layer，左右边缘自动选择位置，竖向钳制在视口内，避免被列表或弹窗裁切。
- 移开卡图、滚动、Escape、关闭弹窗或重新渲染后收起；点击不会固定说明。键盘聚焦卡图也可查看。触摸不模拟悬浮。

## 验证

桌面 1280×720，活动完整规划选择参考队伍后，成员与留影各自显示对应真实技能；移开后 popover 关闭。10/10 已选编成的原生图标加载成功。编辑弹窗的预览技能浮层处于弹窗之上，未被裁切。

浏览器 viewport 覆盖在本轮验证标签未生效，仍为 1280×720，因此不宣称完成手机尺寸的本轮验证。布局沿用 V7，浮层宽度限制为视口减 24px。

脚本语法、129 张卡片技能覆盖及未解析文案检查通过；`git diff --check` 通过。技能文案是真实目录数据，个人养成和计算仍是演示状态。
