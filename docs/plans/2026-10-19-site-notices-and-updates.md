# 公告与更新提示实施计划

1. 实现节点公告存储与固定能力接口；沿用节点读写认证、发布人员白名单及 BFF 来源校验。
2. 控制台增加草稿编辑、预览、发布、撤回和发布版本状态；配置未开放时明确显示未启用。
3. 全局页面接入公告和版本检测，持久记录关闭/稍后，不改变已固定资料。
4. 配置只读公开公告和交付状态路由，支持本地预览与合成数据验收。
5. 运行针对实际边界的 Python/Node 回归与构建，检查公开载荷及文档。

设计来源：用户在本次对话确认前两个功能并要求开始实施。反馈功能不在范围内。
