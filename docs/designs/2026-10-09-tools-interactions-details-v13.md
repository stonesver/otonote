# 工具原型 V13：弹窗、反馈与详细条件

## 本次问题与设计

延续已选择的 D 工作台。保持 V12 的简洁队长技能文字和独立歌曲排行榜。

1. 所有原生 dialog 统一处理外围点击与 Escape。按下和点击都在外侧才关闭，避免内部拖动到外侧误关。队伍、歌曲、卡片与新设置的未应用草稿舍弃；从队伍选择进入编辑时，取消返回队伍选择。计算条件原本即改即生效，外围关闭仅收起面板。
2. 临时消息采用 manual popover，在页面上方居中展示，3.2 秒自动消失，也可手动关闭。弹窗中触发时挂在当前 dialog 内，避免被遮罩盖住。
3. 歌曲选择宽屏三列，中等宽度两列，窄屏一列；谱面按钮 31px 高。颜色、等级、难度和乐队可组合筛选。等级与难度为选择条；五个乐队使用原生圆形 logo，CRYCHIC 暂保留文字选项。筛选区与歌曲滚动区独立，选择不会把首行藏在筛选栏后。
4. 账号加成入口放在卡库/固定队伍条件中，精细发挥放在演出条件中。新设置先编辑后应用，取消不生效。条件标签补齐对应设置，标签说明继续仅悬浮。

## 可体验的新增面板

- 账号加成：按五个乐队展示乐器演示等级；当前五个位置的角色评级；TGW 演示等级。紧凑加减器、直接输入和快捷值。
- 精细发挥：三个预设、Perfect 与 LIFE 滑条、辅助开关、激奏三段名次。支持键盘滑条操作，应用后更新摘要并让既有结果过期。
- 推荐原因：同属性/同乐队配对数量、固定配对数量、五组逐项展开、成员及留影名称、搭配条件、演出技能效果、激奏类型和比较范围。已固定位置在样例候选中保留，并消除重复卡位。
- 估分明细：三种技能顺序示例、触发时间线、各位置贡献、基础与技能分数分项。
- 活动设置：三个活动场景、属性、挑战曲、独立挑战编成；生成结果展示挑战队伍，阶段明细引用设置快照。

## 浏览器验证

1280×720 的独立临时验证页，使用实际 UI 点击、输入、键盘与外围点击完成。

- 歌曲区实测三列，列宽 366px，谱面按钮 31px；Ave Mujica + ≥25 + EXPERT 组合得到 15 首，所有可见谱面符合条件。
- 歌曲选择外围关闭后未确认歌曲不应用。
- MyGO 乐器改到 20 后外围取消，摘要仍为 0 队；重新修改并应用后变为 1 队，顶部显示临时提示，后续确认自动隐藏。
- 弹窗内点击只读配对时，提示挂在 team-picker 中且可见。
- 卡片编辑外围取消后返回队伍选择，再次外围点击关闭；当前队伍保持原值。
- Perfect 预设 97%，连续两次 ArrowLeft 得到 95%；第 2 段名次改为 2，应用后摘要显示 95%P、LIFE 100%、名次 1/2/1。
- 推荐原因包含五组展开项和条件快照；外围关闭成功。
- 计分明细切换较高顺序，顺序与合计同步更新；外围关闭成功。
- 活动选择 Ave Mujica / 翡翠，挑战曲 KiLLKiSS，挑战专用 MyGO 练习编成；生成阶段明细引用正确曲名和队伍。
- 临时验证页 console error / warn 为空；node --check 通过。
- 窄屏仅有 CSS 分支，未在本次浏览器验收。

## 原型边界

全部修改只在 `site/prototypes/tools-redesign/`。无真实账号写入或持久化。

技能文案、图片和歌曲目录来自既有公开快照；乐器等级、角色评级等为编辑流程样例。分数、技能时间、贡献比例、活动奖励为 UI 示例，未接真实计算引擎。加成字段当前按乐队与位置简化，正式接入时必须映射实际账号养成模型。
