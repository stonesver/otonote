# 挑战配队联合上界的正确性说明

本说明对应 `joint-power-score-bound.mjs` 及 `ap-timing-score-bound.mjs`。目标为当前理想演出模型内最高分、120 个技能顺序的平均分，或预设 AP 微操策略下的稳健分数；不改变原生记分规则。

## AP 微操的配队证明

微操目标是同一操作方案在 60／120 帧、77 类均匀时钟及统一 -5／0／+5 ms 偏移下的最低分。因此它不超过其中 60 帧、零相位、零偏移这一条件的分数，可只为该条件构造配队上界。完整评分仍保留全部条件，不把这一放宽当成真实得分。

对手动单点、长条头和普通滑键，将输入放宽到完整 AP 窗口；自动子音符固定。对每个可能的技能激活位置，一颗音符只要最晚输入帧不早于激活帧，就可以在“最早输入帧与激活帧的较大值”计入上界计数。这包含窗口跨越技能启动的音符。不同技能独立选择输入时刻，只会放大累计倍率；倍率增量按真实帧时间与原生 float32 量化生成，直到技能结束。忽略连击丢失，以完整 AP 的 combo 系数取上界；可能由超量回复激活的非负加分效果也予以保留。

这些区间进入同一综合力／技能联合放宽及完整配队分区。计分桶的可修改时间由最大 AP 迟到量和技能命令到达延迟界定；保留原生撤销误差，并用全部命令数覆盖单桶更新数，不能套用正拍的累计更新位置。AP 判定转换、AP 提前释放或负倍率尚不使用此证书；活动逐键／固定结算适配器继续通过原有审计入口。

每支实际队伍完整比较 120 种顺序和六种预设策略，另保留已有操作删减流程产生的方案。方案的某个条件分数已不可能战胜当前最佳时，可以停止后续条件回放，因为目标取最低分。完整配队分区结束且剩余上界不超过已回放最佳分时，证书为 `team_for_chart_ap_policies`。证明域是所选卡库、约束和当前预设策略，不包含任意逐键独立偏移或备选队伍排名；导入方案不能携带有效搜索证书。

## 从原生单音符到功率线性上界

`powerLinearUpperBound` 从已转换为 float32 的倍率常量构造每音符系数 c。保留原生的音符与判定百分比转换、难度倍率、combo 倍率和转换音符数。

原生前缀为非负浮点乘除；计入 int32 综合力转 float32、技能倍率乘法、取整后转回 float32 的误差，`1 + 2^-20` 超过该调用链所需的十余次单位舍入误差。常量连乘的所有前缀限制在 `[2^-60, 2^60]`；对正 int32 综合力，技能倍率前的实际运算仍处于正常浮点范围。技能倍率极小时若进入下溢，最后整数记分为零，不会产生超出上界的正分数。失败或非有限系数回退原有上界。

因此，在支持的纯综合力／歌曲上下文适配器下，每音符原生分数不超过 `P * c * f`。note-score 与 fixed-score 适配器仍由原来的审计入口拒绝，不能利用该系数绕过检查。

## 将技能保留在产生它的配对上

使用原有的技能起止帧与谱面前缀和，得到成员／留影配对 e 在五个技能位置 p 的非负增量 `g(e,p)`。负倍率贡献可以忽略以取得上界，但原有 float32 命令回滚误差 E 不能删除。

设 `B = sum(c)`，对于某合法队伍和某技能顺序，有：

`S <= P * H`，其中 `H = B * (1 + E) + sum(g(e,p))`。

平均分的每张卡在五个技能位置中各出现 24 次，因此以该配对的五位置平均增量替换 g，仍保守覆盖全部 120 个顺序。误差上界对全部顺序一致。

累计技能在理想 AP 下计数单调增加，达到累计上限后不再替换倍率 handle，因此更新次数同时受
音符数与累计上限约束。设命令数上界为 C、所有命令绝对幅度之和上界为 M，每个桶至多被
重新执行 R 次，同一桶内命令数至多为 D。delta 从零开始，第一次加入 float32 命令值是精确的，
所以全部桶的 delta 误差及重放累计不超过 `R * gamma(D-1) * M`。D 按每个激活位置、每种
可用技能的真实起止时间及累计更新帧计数，逐桶取最大后合并五个位置；这放宽了卡片互斥。
无法追踪的累计参数、AP 会触发的提前释放或显式输入帧保留 `D=C`。

设五个技能的绝对峰值之和为 A。精确执行与按桶撤销后的状态均对应有效命令前缀，绝对值
不超过 `1+A`；累计 handle 的替换次数增加 M，不增加同时生效的峰值 A。取 `N=2*C*R+1`，
状态误差可由 `gamma(N)*(1+A) + (1+gamma(N))*R*gamma(D-1)*M` 覆盖，再加原有最终倍率
量化余量。M 仍覆盖旧 handle 移除与新 handle 插入的完整幅度，不能只用最终累计增量。
异常时钟继续使用整曲调用次数的保守界。

对于已验证的理想 AP 累计技能，按激活帧开始累计匹配判定，沿用 float32 计数除法、
倍率量化及封顶值。每次非负倍率增量从其到达帧时间戳持续到技能结束命令，分解为多个
正区间后计算各位置的 g；不会在激活时直接赋予封顶倍率。未知参数或显式输入帧回退封顶
矩形。误差余量独立覆盖原生撤销旧 handle、插入新 handle 与多技能叠加的舍入。

C 和 M 还可按每张留影取所有可用成员配对的最大值，再求最多五个不同留影的最大和。
这放宽成员、角色及必选约束，仍覆盖每支合法队伍，却不会重复使用一张稀有累计技能
留影。分区包络缓存必须同时包含这些预算值，不能仅按效果种类复用不同域的误差预算。

数学放宽产生的单音符上界可能超出原生 int32 范围；这时该上界返回正无穷，不能用于剪枝。
实际队伍计分仍严格执行原生整数范围检查，不截断或包装溢出分数。

配对自身的 p(e) 是原有整数匹配模型中的实际综合力贡献。固定队长后 `P = sum(p(e))`。不能从一个配对取综合力、另一个配对取技能当作真实可行队伍；新松弛在每条边上保留它们的对应关系。

## 正参数线性松弛

对任意正参数 lambda，由平方非负：

`4 * lambda * P * H <= (lambda * P + H)^2`。

因此，只要求出所有合法队伍的 `lambda * P + H` 的非负上界 Z，就有 `S <= Z^2 / (4 * lambda)`。

五位置 mask DP 最大化每条配对的 `lambda * p(e) + g(e,p)` 之和。它保留角色互斥、五个技能位置各用一次、队长及已锁定配对；留影唯一性暂时放宽，所以可行空间只会扩大。未带价格时，同角色、同有效技能行为的配对只保留最大综合力，属于该松弛内部的等价聚合，不从真实搜索空间删卡。

最多四次参数更新只用于收紧上界。每次更新产生的任意正 lambda 都独立有效，不依赖迭代收敛，不把 DP 返回的虚拟队伍当成真实推荐。

## 根节点资源价格

对每张留影设置非负价格 mu(s)。将配对权重减去对应价格，在 DP 外加回全部非零价格：

`Z(lambda,mu) = B*(1+E) + sum(mu(s)) + max sum(lambda*p(e)+g(e,p)-mu(s(e)))`。

任何合法队伍对每张留影至多使用一次，所以加回的价格至少等于合法队伍被扣除的价格。这个表达式仍为合法队伍线性目标的上界。

更新价格的步长参考一支合法最大综合力队伍在该线性模型中的值；它不是原生分数。即使步长没有改善价格，也不能影响已有上界的安全性。根节点最多十二轮，保留已经得到的最小安全上界；非根节点避免这项额外成本。

带价格的 DP 权重可能为负数，不能只对相消后的结果乘一个相对误差。实现额外按最大综合力项、最大技能项、最大价格和价格绝对值总和预留绝对误差，再向上平方并取整。前缀求和与区间相减也保留独立绝对误差余量；超过十万个音符时回退旧路径。

## 搜索剪枝与证明

新上界和旧上界都覆盖同一分区，因此可取两者较小值。子分区属于父分区，可继承父上界；这不会改变合法空间覆盖。

当前节点的最大综合力代表队伍可能很弱。在正式重放其 120 个技能顺序前，把这五个配对全部设为必选，计算该完整队伍的安全上界。若不能超过已知最佳分数，可以跳过这支队伍的评分，但必须继续登记原分区的全部子空间。

只证明第一名时，全部未处理分区的最大上界不超过当前合法队伍的完整评分，即可结束。第二、第三个已计算队伍不参与停止条件，也不会被标为已经证明其排名。

## 验证边界

独立穷举覆盖成员选择、角色变体、留影配对、队长、最高／平均分及必选／禁用分区；另以原生单音符核对 int32 边界和不同浮点倍率。原有 30／60／120 fps、桶回滚和事件适配器回归继续运行。

证书沿用当前模型的固定非队长物理站位约定，技能顺序完整比较。不据此声明所有实机输入时序或未纳入模型的物理站位都已验证，也不扩大到动态玩家情境。
